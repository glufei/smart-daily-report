# ADR-001：采用 httpx 作为 HTTP 客户端

- **状态**：已采纳
- **背景**：GitHub 与飞书 API 需要统一请求、超时、连接池和可控 Mock；性能目标要求避免串行网络等待成为固定瓶颈。
- **选项**：`requests`（同步生态成熟）、`httpx`（同步/异步 API）、`aiohttp`（异步专用）。
- **决策**：采用 `httpx`，当前 CLI 使用同步 API。
- **理由**：同一库支持同步和异步，调用方可注入客户端与 MockTransport；重试和 HTTP 状态处理留在确定性代码。
- **后果**：所有请求设置超时；模块只依赖传入 client，不创建不可控的全局连接。
