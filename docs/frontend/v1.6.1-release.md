# v1.6.1 发布说明

v1.6.1 是网页品牌文案补丁。网页页眉、页脚和浏览器标签标题统一显示“智能日报”，网页不再显示个人姓名；邮件主题、邮件正文和飞书标题继续使用“高畅智能日报”。

本次仅调整网页文案、对应的回归检查、版本号和说明文档，不改变采集逻辑、日报数据、时区处理、邮件/飞书内容或推送流程。v1.6.0 的跨渠道版式与数据行为保持不变。

## 验证

- 前端单元测试：147 项通过。
- 桌面与手机浏览器端到端测试：16 项通过。
- TypeScript 类型检查通过。
- 前端生产构建通过。
- Python 全量回归沿用 v1.6.0 发布验证：335 项通过，覆盖率 95.35%；本次变更未修改 Python 代码。
