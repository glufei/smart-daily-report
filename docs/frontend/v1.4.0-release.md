# v1.4.0 变更记录（已发布）

- GitHub 标签：[`v1.4.0`](https://github.com/glufei/smart-daily-report/releases/tag/v1.4.0)
- 发布状态：2026-10-11 已发布，标签指向 v1.4.0 合并提交。

## 变更内容

- 每位成员日报新增“今日总结”，确定性展示代码提交、已完成任务及协作消息数量。
- 来源成功但无成员记录时显示“0 条”；来源失败时显示“获取失败，数量未知”。
- 保留三类来源明细；Markdown（飞书）与 HTML（邮件）规则一致。
- 不调用 AI、不改写源内容，不修改数据模型、HTTP API、历史日报、采集或推送流程。
