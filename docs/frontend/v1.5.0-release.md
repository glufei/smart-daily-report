# v1.5.0 版本说明

- 版本：1.5.0
- 变更 PR：[PR #8](https://github.com/glufei/smart-daily-report/pull/8)
- 发布：2026-10-11 已发布至 GitHub Releases；标签 v1.5.0 指向 main 合并提交 `ce7a2e3`。

## 主要变化

- 每天都可以生成、预览和推送日报，周末及配置节假日不再拦截；其余日期、安全、版本、渠道和收件人校验保持不变。
- 成员摘要继续按实际采集记录统计，正文和页面明确分为“GitHub｜代码提交”与“飞书｜任务与工作消息”，减少不同来源内容混淆。
- 生成时间在页面按团队时区显示，数据库仍保存 UTC；只读模式可明确指定展示时区。
- 修正 Windows Playwright/Vite 测试服务器清理，两个浏览器测试套件可以自然退出。
- Python 包、OpenAPI、前端包与锁文件版本统一为 1.5.0；README、运行说明和 SDD 文档同步更新。

## 验证

- 前端：145 项通过；语句/分支/函数/行覆盖率为 97.38%/94.89%/98.88%/100%。
- Playwright：只读 14 项、操作 38 项通过，桌面与移动视口均覆盖；使用合成外部服务边界，没有真实采集或通知发送。
- TypeScript 检查、生产构建、npm audit 与 git diff 检查通过。
- 独立人工缺陷审查未发现可确认的 P1–P3 问题。当前没有可调用的自动 Bugbot 工具，GitHub 未配置 CI 状态检查；本次不将其表述为自动审查或 CI 通过。

## 升级说明与边界

前端和后端应从同一 v1.5.0 版本升级。配置中的 team.holidays 仍可读取以兼容已有配置，但不再阻止任何日期生成或推送。历史日报不会重算，已有收件人选择和发送确认流程保持不变。

Python 依赖漏洞审计未执行：运行环境没有安装 pip-audit。npm 依赖审计结果为 0 项漏洞。真实外部平台、真实邮件/飞书发送以及完整负载性能不是本轮自动化测试范围。
