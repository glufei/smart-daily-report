# v1.6.4 版本说明

此版本让飞书 `21001` 访问策略拒绝显示为可识别的错误。后端保留 `x-tt-logid` 请求追踪 ID 到本机结构化日志，操作页面提示管理员按追踪 ID 排查；平台拒绝不会被自动重试或绕过。该错误发生在签发 `tenant_access_token` 时，策略本身须由飞书租户管理员或平台支持处理。

邮件主题统一使用日报名称和报告日期，生成时刻继续放在正文中，避免用具体时间标记日报版本。公开 README 已移除个人姓名、私人工作区路径、历史数据说明和特定时段推送描述。
