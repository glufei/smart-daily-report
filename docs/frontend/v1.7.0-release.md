# v1.7.0 发布说明

此版本将对外展示的日报改为汇总版。网页、邮件和飞书通知只展示每位成员的代码提交、已完成任务、协作沟通数量，以及“已获取记录合计”和“有记录类别”；网页与邮件增加数量对比条。汇总数据来自已成功采集的记录，不评价工作量或成果质量。来源失败时数量未知，不计入合计；不展示逐条提交标题、链接、任务名称、消息正文或原始 ID。

原始采集记录仍保存在本机 SQLite，并由本机 API 返回。**展示层隐藏明细不等于数据库或 API 已脱敏。** 仓库是公开的；本地 `.env`、`config.yaml` 与数据库由 Git 忽略，不应加入提交或发布附件。没有新增定时运行或自动部署功能。

## 从旧版升级

1. 更新代码后重启前后端，并使用当前操作模式预览目标日期。旧的 Markdown/HTML 日报是快照，不会自动变为汇总版；旧快照会被当前操作模式拒绝推送。
2. 对需要发送的日期重新点击“采集并生成”，核对来源状态和汇总内容，再分别确认邮件收件人与飞书目标。重新生成会替换该日期的本机快照，无法撤回已经发出的旧邮件或群消息。
3. 若希望收录指定飞书群中已映射成员发送的全部消息，可将 `team.report_keywords` 设为 `[]`；保留关键词列表时仍只收录命中消息。修改配置后重启后端并重新生成对应日期。

本版本还完善了飞书时间的中国标准时间展示、操作页面反馈和收件人确认；GitHub Actions 负责测试和打包，**不会部署或运行日报**。具体本机步骤见[README](../../README.md)与[本地运行说明](local-run.md)。
