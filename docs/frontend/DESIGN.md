# 只读日报设计交接

依据已确认 v1.1 规范，设计来自 OpenDesign 0.24.1 的真实 UI；初版和第二版原文件、截图及输入见 [证据记录](opendesign-evidence.md)。最终采用第二版的字体和控件尺寸。

## 布局与令牌

- 白色顶栏：宋体“智能日报”、只读标签、桌面副标题。
- 页面背景 `#f2f4f8`，白色卡片 `#fff`，正文 `#1c2633`，次级文字 `#5b6572`，分隔线 `#e3e7ee`，主色深蓝 `#1d3a5f`，错误 `#b3261e`，警告 `#9a5b00`。
- 内容容器最大 920px，左右边距 20px；间距 8/12/20/28/48px，卡片圆角 14px，控件圆角 8px。
- 展示字体 Songti SC/SimSun/Georgia，正文系统字体/微软雅黑，时间与仓库等宽；正文与记录 16px，日期标签 14px，输入/查询按钮高度 48px，按钮 16px。
- 查询卡片 → 结果区 → 页脚。成员按历史顺序纵向排列，卡片中依次代码提交、任务进展、协作沟通，分隔线组织三板块。
- ≤600px 日期输入、按钮纵向；≤480px 隐藏顶栏副标题。长团队名、记录、URL 与时间均可换行，容器及子项允许收缩。

## 状态与交互

| 情形 | 呈现 |
|---|---|
| 查询前 | 选择日期查看日报 |
| 加载 | 正在加载日报…；清除旧内容 |
| 200 | 团队、日期、带时区生成时间、全部成员、三板块与来源状态 |
| 404 | 页面级“该日期尚无日报” |
| 400/500/网络/超时/坏响应 | 页面级“查询失败”及对应固定安全文案，显式“重新查询” |
| 已有日报，成功来源零记录 | 板块级“今日无记录” |
| 已有日报，来源失败 | 顶部说明失败来源，各成员对应板块文字及边框“数据获取失败” |

日期输入有可关联 label“报告日期”，查询/重查按钮有可访问名称，焦点环 2px 深蓝。原生日期控件可能需要多次 Tab 编辑年/月/日，之后可 Tab 到查询按钮并 Enter 提交。结果区 aria-live，查询错误 role=alert，加载 role=status；失败不能只靠颜色。产品支持更换日期/再次查询取消旧请求，10 秒上限，不自动重试。

## 设计到产品的明确差异

1. 移除原型演示状态面板、演示日期映射与虚构数据说明，产品只查询真实只读 API。fixture 不打包到生产入口。
2. 第二版手机截图存在日期与按钮间异常空白：column 下 `.query-field` 的 260px flex-basis 撑高字段。已尝试在 OpenDesign 提交额外修正，但工具因检测到用户输入拒绝操作；该额外修正未生成，不能宣称为 OpenDesign 第三版。产品媒体查询使用 `flex:none;width:100%` 修复并留下实现截图。
3. 产品显式展示三个来源状态，真实记录的时间、提交统计、任务变化、群名与安全来源链接来自 DTO；不从数组长度推测成功状态。
4. 记录由 React 文本节点渲染，禁止注入保存的 HTML；链接仅 HTTP(S)，新标签页加 `noopener noreferrer`。没有采集、生成、推送、管理、编辑、删除、登录控件。

初版与第二版两种视口 × 六种状态以及键盘查询共 28 项检查通过，见 `prototypes/checks.json`。两版都仅含虚构输入，手机异常空白为公开的交接修正项，不隐瞒为完成的 UI 第三次迭代。
