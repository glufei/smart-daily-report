# 智能日报生成器 v1.3.0

发布日期：2026-10-11。交付方式由用户明确授权：[PR #4](https://github.com/glufei/smart-daily-report/pull/4) → main → [v1.3.0 Release](https://github.com/glufei/smart-daily-report/releases/tag/v1.3.0)。实际合并提交、标签与发布时间以GitHub记录为准；原v1.2.0标签保留。

## 本次变化

- 查询执行结果显示加载、完成时间、执行日期、状态和错误；查询成功与附带预览失败/超时分别提示。
- 主动预览显示加载/完成/错误/10秒超时，成功后定位正文；刷新失效时清除旧发送依据。
- 邮件默认不选收件人，从后端配置地址中勾选，显示人数，发送前确认具体地址；后台保存并使用本次目标快照。
- 允许独立确认的新请求再次发送同版本邮件，不增加逐收件人去重。保留同请求去重、断线不自动重发及飞书原限制。
- 同步SDD规范、README和本机运行说明，关闭接口文档旧状态标题问题；未增加依赖或修改工作日规则。

## 升级与启动

详细双窗口操作见 [README](../../README.md#一当前电脑直接启动) 和 [本机运行说明](local-run.md)。当前电脑保留已有配置与数据库，在配置目录启动后端并将PYTHONPATH指向新源码；前端也从新版目录启动。停止旧服务后重新启动两端。

**前后端必须一起升级**：旧邮件请求缺email_recipients返回400，不能回退为发送全部邮箱。历史操作缺目标显示“未记录”，不改写旧库。CLI仍沿用配置全量邮箱；页面推送仅发送确认的子集。未知结果先核对真实收件，不自动重发。

## 验证及边界

- 最终功能代码：Python314 passed/95.24%，前端135 passed；四个前端业务模块逐文件四项≥90%。只读/操作浏览器14+38，两视口；类型与两模式生产构建通过。
- 独立整体审查的重要问题先RED2再GREEN2并全量回归；发布元数据同步后全量Python314、前端135、两模式构建和六处版本一致性检查再次通过；依赖锁仅更新根包版本。
- 实际配置GET-only和数据库副本核对通过，原库不变，无真实采集或通知。**本轮选择性邮件的实际收件尚未验收**，不能用旧版收件或受控SMTP替代。
- 既有Starlette/httpx弃用提示和浏览器环境提示保留；没有把服务商受理等同于进入收件箱。

详细测试、裁决和历史审查记录见 [验收与交付说明](operation-feedback-email-selection-acceptance.md) 与 [TDD记录](operation-feedback-email-selection-tdd.md)。本轮发布不自动推送日报，不修改私人配置或历史数据。
