> 已于 2026-10-11 发布。v1.3.1 以 PR #5 合并提交为发布源；v1.3.0 标签及历史发布说明保持不变。

## 本次更新

- 隔离已超时的旧操作响应，避免迟到的 POST 或自动预览清除新操作的计时器、提交锁或忙碌状态。
- 严格校验飞书 `sender` 字段：只有字段缺失或 `null` 按未分配处理；列表、空字符串和数字等非字典值会作为来源级无效载荷处理。
- 将前端开发依赖 `source-map-js` 更新至 1.2.2；其他依赖版本未变更。
- README、本机运行说明和 SDD 规范同步到 v1.3.1，并记录完整发布验收范围。
