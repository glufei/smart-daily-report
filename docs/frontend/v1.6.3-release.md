# v1.6.3 版本说明

此版本在邮件主题中加入了生成时刻，并在邮件正文展示报告生成时间；操作页面支持选择已配置的收件人。v1.6.4 已将主题简化为日报名称和报告日期，正文继续保留生成时间。相同日期可以再次发送，发送前仍需重新确认收件人及内容。

系统不会自动生成改进内容或定时推送。每次推送都由操作者检查预览并确认，采集失败的来源继续明确标记为未知数量。

## 验证与限制

- 邮件正文的生成时间按 `Asia/Shanghai` 显示。
- 邮箱收件人来自服务器配置；页面每次要求明确选择并确认。
- SMTP 受理不等于收件箱实际到达，发送后需核对邮箱。
- 本地日报库按报告日期保存最新快照；重新生成会替换本地该日期的日报。
