# v1.6.3 版本说明

同一天向老师提交两版日报时，邮件主题现在根据各自的生成时间标为“高畅智能日报（日期 HH:MM版）”；邮件正文抬头显示完整的中国标准时间。这样在 Gmail、QQ 邮箱中，两封邮件的版本和生成时刻都容易辨认。程序不会自动生成“改进点”，也不会虚构新增记录；第二版应在实际内容改进并重新采集后发送。

在作者本机，新增收件人写入受 Git 忽略的真实运行配置 `team.smtp.recipients`，并重启后端。公开仓库的示例配置保留占位地址，不包含私人收件人。页面上的邮件收件人由服务器配置提供；每次发送都须重新勾选并确认。项目不会代替用户在 20:00、21:00 自动发送。

## 验证与限制

- 邮件主题测试验证同一天 20:00、21:00 生成的两版具有不同主题；生成时间按 `Asia/Shanghai` 显示。
- Python 全量测试 337 项通过，覆盖率 95.33%；前端测试 148 项通过，类型检查和生产构建通过。
- 来源获取失败时仍标记“数量未知”，不得把飞书失败视为零记录。SMTP 受理不等于收件箱实际到达，发送后需核对邮箱。
- 本地历史库按报告日期保存最新快照；第一版邮件保留在收件人邮箱中，但第二次生成会替换本地该日期的日报。需要留存本地两版时，应在第二次生成前导出第一版。
