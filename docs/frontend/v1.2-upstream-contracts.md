## 飞书任务

使用 tenant_access_token 读取服务器配置的已授权 tasklist GUID，不使用用户 OAuth 搜索。
[官方清单请求 SDK](https://raw.githubusercontent.com/larksuite/oapi-sdk-python/v2_main/lark_oapi/api/task/v2/model/tasks_tasklist_request.py)明确 GET、TENANT/USER 和 query 参数；[官方搜索请求](https://raw.githubusercontent.com/larksuite/oapi-sdk-python/v2_main/lark_oapi/api/task/v2/model/search_task_request.py)仅支持 USER，与旧 tenant 搜索模式冲突。

GET /open-apis/task/v2/tasklists/{tasklist_guid}/tasks，page_size=100/completed=true/user_id_type=open_id，后页带 page_token，无 body/创建日期过滤。清单 GUID 在 URL 路径编码；items/has_more 和业务成功码严格校验，缺/重复下一页令牌整体失败。

[官方 TaskSummary](https://raw.githubusercontent.com/larksuite/oapi-sdk-python/v2_main/lark_oapi/api/task/v2/model/task_summary.py)提供 guid/summary/completed_at/members；[官方 Go 模型](https://raw.githubusercontent.com/larksuite/oapi-sdk-go/v3_main/service/task/v2/model.go)记录完成时间毫秒、0 未完成。当前兼容整数和数字字符串；非负、日期窗口左闭右开；更新时间不能证明完成。每个 user/assignee 投影一条，跨清单/页按任务 GUID 与负责人去重。无负责人仅产生未映射诊断，不归到任意成员。完成前态未知，页面不画虚构迁移；重新打开任务不能复原历史完成事件。

配置保留 lark_project_ids/lark_task_search_path 名称，默认路径已迁移清单模板；启用任务时显式旧 search 或其他路径拒绝。请使用 config.yaml.example 更新本地配置。未启用任务仍可保留旧字段，但不执行旧接口。

## 飞书消息与授权

[官方历史消息接口](https://open.feishu.cn/document/server-docs/im-v1/message/list)：GET /im/v1/messages，服务器 chat_id、配置时区的秒级时间窗口、page_size=50、下一页令牌。任务/消息共享确定性单次 Token 刷新与重放；再次鉴权失败整体失败，不能作为正常空结果。敏感过滤先于持久化和预览；浏览器仅含内部成员 ID。

权限核验仍待 Task18：开发者控制台须核对对应任务清单读取和群历史消息能力，应用发布/租户审批、任务清单的应用访问权限、机器人所在群和数据可见范围均须生效。不能仅凭 tenant Token 已取得就宣称具有清单/群权限。本轮官方SDK确认Token类型/字段，真实接口错误明确要求task:tasklist:read或write，已选择并验证read生效。正确清单GUID已核对，具体数据访问仍待应用身份读取成功；官方动态文档页无法由检索工具完整读取，不猜测其余scope。未核对前不勾选真实权限验收。
