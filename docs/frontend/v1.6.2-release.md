# v1.6.2 发布说明

v1.6.2 将网页和邮件中的 GitHub 提交时间统一显示为中国标准时间（Asia/Shanghai，UTC+08:00），并明确标注时区。例如 GitHub 时间 `2026-10-12T12:37:19Z` 会显示为 `2026-10-12 20:37:19（中国标准时间，UTC+08:00）`。

此变更只转换显示结果，原始提交时间、数据库存储、报告日期和采集范围都不变。其他来源的时间显示方式不变。

## 验证

- Python 全量测试：335 项通过，覆盖率 95.36%。
- 前端单元测试：148 项通过。
- 桌面与手机浏览器端到端测试：16 项通过。
- TypeScript 类型检查和前端生产构建通过。
- 日期转换回归覆盖 `12:37:19Z` 显示为上海时间 `20:37:19`。
