# v1.2.0 发布说明

版本：1.2.0。验证日期：2026-10-05；全部已确认业务验收与最终回归通过。正式发布状态以[GitHub v1.2.0 Release](https://github.com/glufei/smart-daily-report/releases/tag/v1.2.0)为准。

## 已实现的变化

- React操作页面调用真实FastAPI后端，采集GitHub提交及飞书已授权清单的当日完成任务、符合规则的群消息，并保存到SQLite历史库。
- 采集并生成只产生预览；推送独立确认日期、内容版本及固定渠道目标，分别报告SMTP与飞书Webhook结果。
- 操作令牌仅用于本机后端鉴权，GitHub/飞书/SMTP凭证保留在后端。页面没有Mock成功回退。
- 原幂等键用于恢复查询，断线和结果不明不会自动新建发送请求；来源失败与正常零记录分开展示。
- 保留只读模式、基础CLI及工作日限制。沿用React/OpenDesign的既有界面。
- 空令牌验证给出本地提示并聚焦，未验证时生成禁用原因明确，避免按钮无反馈的困惑。
- 审查补齐消息异常页校验、GitHub详情限流/文件分页及Markdown文本转义；详情达到上游3000文件边界时明确失败，避免静默截断统计。

## 已有验证

2026-10-05发布前完整回归：pytest286项、95.03%；Vitest102项，四个业务模块逐文件四项覆盖率≥90%；只读浏览器14项、操作模式26项；类型检查、构建、基础CLI及启动复现通过。Python有一条既有Starlette/httpx弃用警告。浏览器HTTP/SMTP边界替身不能替代真实外部验收。

真实GitHub2条提交与飞书完成任务1条已分别核对到SQLite/API/页面。2026-10-01同一日报版本已独立推送，用户确认邮件和飞书两处收到、内容一致、无重复。10月5日真实工作日消息4条已完成源/SQLite/API/React核对，零发送；9月26日周六样本不充当该证据。

四次真实生成分别耗时1640ms、3687ms、2156ms、1953ms；权限/资源失败记录保留，真实限流未遇到，重试与限流逻辑有离线验证。现有样本不等于完整负载性能保证。真实多页任务和Chrome以外浏览器仍未在线验证。
