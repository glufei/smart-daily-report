# v1.6.0 版本说明

- 版本：1.6.0
- 发布日期：2026-10-12
- 发布标签：`v1.6.0`，基于 GitHub `main`。

## 主要变化

- 邮件、网页和飞书统一使用“高畅智能日报”品牌标题。
- 邮件正文使用最大宽度 860px 的自适应表格，摘要指标卡片化，并以不同颜色和独立卡片区分 GitHub 与飞书内容。
- 网页阅读列最大宽度调整为 1080px，增强桌面端可读性，并保持移动视口不横向溢出。
- 飞书 Markdown 以分隔线清晰分开 GitHub 与飞书来源板块。
- 更新 README 与本机启动说明，保留 v1.5.0 及更早版本的发布记录。

## 验证

- Python：335 项通过，覆盖率 95.35%。
- 前端单元测试：147 项通过。
- Playwright：桌面与手机视口共 16 项通过。
- TypeScript 类型检查与前端生产构建通过。
- 使用虚构内容完成 QQ 邮箱样式验收；测试邮件只发送到个人测试邮箱，不含真实日报记录。
- 后端测试保留一条 Starlette/httpx TestClient 弃用警告。

## 升级说明

前后端版本统一升级到 1.6.0。此版本只调整日报品牌和展示版式，不改变日报采集范围、数据模型、发送目标选择或推送确认流程。历史日报继续按其保存时的内容展示，不会自动重算。
